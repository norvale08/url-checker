# Асинхронный сервис проверки списка URL

Элегантное fullstack-приложение для асинхронной проверки доступности веб-ресурсов с премиальным пользовательским интерфейсом.

## 🎯 Обзор проекта

Сервис позволяет создавать задания на проверку списка URL-адресов, отслеживать прогресс в реальном времени и получать детальную статистику по каждому URL. Приложение выполнено в роскошном и изысканном стиле с использованием современных анимаций и визуальных эффектов.

## ✨ Возможности

- **Асинхронная обработка** — Проверка URL выполняется в фоновом режиме с возможностью одновременной обработки нескольких заданий
- **Отслеживание прогресса** — В реальном времени отображается статус проверки каждого URL с процентами выполнения
- **Детальная статистика** — Для каждого URL показывается HTTP-статус, время ответа и сообщения об ошибках
- **Управление заданиями** — Возможность отмены заданий в процессе выполнения
- **Автоматический опрос** — Периодическое обновление статуса активных заданий
- **Премиальный UI** — Роскошный дизайн с золотыми акцентами, анимациями и эффектами glassmorphism

## 🛠 Технологический стек

### Бэкенд
- **Node.js** + **TypeScript** — Основная платформа
- **Express** — REST API фреймворк
- **Axios** — HTTP-клиент для выполнения HEAD-запросов
- **In-memory хранилище** — Map-based хранилище данных (без БД)

### Фронтенд
- **React 18** + **TypeScript** — UI фреймворк
- **Vite** — Сборщик и dev-сервер
- **Zustand** — Управление состоянием
- **Axios** — HTTP-клиент для API запросов
- **CSS Variables** — Система стилизации с премиальной темой

## 📦 Установка и запуск

### Требования
- Node.js 18+
- npm или yarn
- Docker и Docker Compose (опционально)

### Вариант 1: Docker (рекомендуется)

```bash
# Клонирование репозитория
git clone <repository-url>
cd url-checker

# Запуск через Docker Compose
docker-compose up --build
```

После запуска:
- **Фронтенд**: http://localhost
- **Бэкенд API**: http://localhost:5000

### Вариант 2: Ручной запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd url-checker

# Установка и запуск бэкенда
cd backend
npm install
npm run dev

# В новом терминале: установка и запуск фронтенда
cd frontend
npm install
npm run dev
```

После запуска:
- **Фронтенд**: http://localhost:5173 (или другой порт Vite)
- **Бэкенд API**: http://localhost:5000

## 📚 API документация

### Создать задание
```http
POST /api/jobs
Content-Type: application/json

{
  "urls": ["https://example.com", "https://google.com"]
}
```

**Ответ:**
```json
{
  "jobId": "uuid-string"
}
```

### Получить список заданий
```http
GET /api/jobs
```

**Ответ:**
```json
[
  {
    "id": "uuid-string",
    "createdAt": "2024-01-01T00:00:00.000Z",
    "status": "completed",
    "totalUrls": 2,
    "stats": {
      "success": 1,
      "error": 1
    }
  }
]
```

### Получить детали задания
```http
GET /api/jobs/:id
```

**Ответ:**
```json
{
  "id": "uuid-string",
  "status": "completed",
  "urls": [
    {
      "url": "https://example.com",
      "status": "success",
      "httpStatus": 200,
      "duration": 1234,
      "startTime": "2024-01-01T00:00:00.000Z",
      "endTime": "2024-01-01T00:00:01.234Z"
    }
  ]
}
```

### Отменить задание
```http
DELETE /api/jobs/:id
```

**Ответ:**
```json
{
  "message": "Job cancellation requested",
  "job": { ... }
}
```

## 📋 Статусы заданий

- **pending** — Задание создано, ожидает обработки
- **in_progress** — Задание обрабатывается
- **completed** — Задание успешно завершено
- **cancelled** — Задание отменено пользователем
- **failed** — Все URL завершились с ошибками

## 📊 Статусы URL

- **pending** — URL ожидает проверки
- **in_progress** — URL проверяется
- **success** — URL успешно проверен
- **error** — Ошибка при проверке URL
- **cancelled** — Проверка URL отменена

## ⚙️ Конфигурация

### Бэкенд
- Порт: `5000` (можно изменить через переменную окружения `PORT`)
- Лимит параллельных запросов: 5
- Задержка перед запросом: 0-10 секунд (случайная)

### Фронтенд
- API URL: `http://localhost:5000/api` (настроен в `frontend/src/api/index.ts`)
- Интервал опроса: 2 секунды

## 🐛 Устранение неполадок

### Бэкенд не запускается
```bash
# Проверить, занят ли порт 5000
netstat -ano | findstr :5000

# Убить процесс, если порт занят
taskkill /PID <PID> /F
```

### Фронтенд не подключается к API
- Убедитесь, что бэкенд запущен на порту 5000
- Проверьте CORS настройки в `backend/src/server.ts`
- Проверьте API URL в `frontend/src/api/index.ts`
