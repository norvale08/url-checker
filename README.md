# Асинхронный сервис проверки списка URL

Приложение для проверки доступности веб-ресурсов.

## Возможности

- Проверка списка URL с ограничением параллелизма (5 запросов)
- Отслеживание прогресса в реальном времени
- Статистика по каждому URL (HTTP-статус, время ответа, ошибки)
- Отмена заданий в процессе выполнения
- Автоматическое обновление статуса

## Технологический стек

**Бэкенд:** Node.js, TypeScript, Express, Axios

**Фронтенд:** React 18, TypeScript, Vite, Zustand, Axios

## Установка и запуск

### Docker
```bash
docker-compose up --build
```
Фронтенд: http://localhost  
Бэкенд: http://localhost:5000

### Ручной запуск
```bash
# Бэкенд
cd backend
npm install
npm run dev

# Фронтенд
cd frontend
npm install
npm run dev
```
Фронтенд: http://localhost:5173  
Бэкенд: http://localhost:5000

## API

### POST /api/jobs
Создать задание
```json
{
  "urls": ["https://example.com"]
}
```
Ответ: `{"jobId": "uuid"}`

### GET /api/jobs
Список заданий

### GET /api/jobs/:id
Детали задания

### DELETE /api/jobs/:id
Отменить задание

## Конфигурация

- Порт бэкенда: 5000 (переменная `PORT`)
- Лимит параллельных запросов: 5
- Задержка перед запросом: 0-10 секунд
- Интервал опроса: 2 секунды
