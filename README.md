# Асинхронный сервис проверки списка URL

Fullstack-приложение для асинхронной проверки доступности веб-ресурсов.

## Возможности

- Асинхронная проверка списка URL с ограничением параллелизма (5 запросов)
- Отслеживание прогресса в реальном времени
- Детальная статистика по каждому URL (HTTP-статус, время ответа, ошибки)
- Отмена заданий в процессе выполнения
- Автоматический опрос статуса активных заданий

## Технологический стек

**Бэкенд:** Node.js, TypeScript, Express, Axios, in-memory хранилище

**Фронтенд:** React 18, TypeScript, Vite, Zustand, Axios

## Установка и запуск

### Docker
```bash
docker-compose up --build
```
Фронтенд: http://localhost  
Бэкенд: http://localhost:5000

### Ручной запуск
```bash
# Бэкенд
cd backend
npm install
npm run dev

# Фронтенд (в новом терминале)
cd frontend
npm install
npm run dev
```
Фронтенд: http://localhost:5173  
Бэкенд: http://localhost:5000

## API

### POST /api/jobs
Создать задание на проверку URL
```json
{
  "urls": ["https://example.com"]
}
```
Ответ: `{"jobId": "uuid"}`

### GET /api/jobs
Получить список заданий

### GET /api/jobs/:id
Получить детали задания

### DELETE /api/jobs/:id
Отменить задание

## Конфигурация

- Порт бэкенда: 5000 (переменная окружения `PORT`)
- Лимит параллельных запросов: 5
- Задержка перед запросом: 0-10 секунд (случайная)
- Интервал опроса: 2 секунды
